# 활동 말풍선 5h·7d 남은 사용량 설계

## 목표

동시에 여러 작업이 실행될 때 활동 말풍선의 `총 N개 작업 중` 헤더 오른쪽에
Codex의 5시간·7일 한도 잔여율을 짧게 표시한다.

예시:

```text
총 3개 작업 중                       5h 42%  7d 68%
```

## 범위

- 여러 활동이 `sections`로 묶인 집계 헤더에만 표시한다.
- 5시간 한도는 `5h`, 7일 한도는 `7d`로 표시한다.
- 각 값은 사용률이 아닌 남은 비율의 정수다.
- Codex가 실제로 작업 중일 때만 표시한다.
- 계정별 상세 카드, 단일 작업 제목, 완료·오류·사용량 전용 말풍선은 변경하지 않는다.

## 데이터 기준

`CodexWatcher`가 `token_count`에서 받은 최신 `rate_limits`를 사용한다. 별도 API를
호출하지 않아 말풍선 갱신이 네트워크 상태나 계정 API 제한에 영향을 받지 않게 한다.

- `window_minutes === 300`: 5시간 한도
- `window_minutes === 10080`: 7일 한도
- 남은 비율: `round(100 - used_percent)`
- 사용률은 0~100 범위로 보정한다.
- 초기화 시각이 이미 지났으면 남은 비율을 100으로 본다.
- 기간이나 사용률이 유효하지 않은 창은 표시하지 않는다.
- 둘 중 하나만 유효하면 해당 배지만 표시한다.
- 가장 최근에 `usage-updated`를 보낸 활성 Codex 세션의 값을 사용한다.

## 구조

### `src/activity-usage.js`

rate limit 원본을 화면용 배지 배열로 바꾸는 순수 모듈을 추가한다.

```js
[
  { key: "5h", remainingPercent: 42, ariaLabel: "5시간 42% 남음" },
  { key: "7d", remainingPercent: 68, ariaLabel: "7일 68% 남음" },
]
```

기간 판별, 초기화 시각, 숫자 보정은 이 모듈만 담당한다. 활동 상태 저장소와 DOM
renderer는 rate limit 원본 형식을 알지 않는다.

### `src/main.js`

- `usage-updated`에서 최신 배지 배열을 보관한다.
- Codex가 작업 중이고 `buildActiveActivityBubble()` 결과가 다중 section일 때만
  `usageBadges`를 붙인다.
- 새 사용량 이벤트가 오면 현재 활성 말풍선을 다시 그린다.
- Codex 작업이 모두 끝나면 외부 provider 활동에 이전 Codex 수치가 남지 않게 숨긴다.

### `src/bubble.js`와 `src/bubble.css`

- 집계 헤더의 제목 뒤에 `usageBadges`를 고정 폭 영역으로 렌더링한다.
- `5h 42%`, `7d 68%` 두 배지는 줄바꿈하지 않고 tabular 숫자를 사용한다.
- 제목은 기존처럼 남은 폭에서 말줄임 처리한다.
- 사용자 말풍선 글자색을 따르는 muted 색상만 사용하고 새 장식이나 애니메이션은
  추가하지 않는다.
- 각 배지는 `aria-label`로 `5시간 42% 남음`, `7일 68% 남음`을 제공한다.

## 상태 흐름

1. 활성 Codex rollout이 `token_count`와 `rate_limits`를 기록한다.
2. `CodexWatcher`가 `usage-updated`를 발행한다.
3. main process가 순수 변환 모듈로 5h·7d 배지를 계산한다.
4. 활성 활동 말풍선 데이터의 집계 헤더에 `usageBadges`를 붙인다.
5. bubble renderer가 제목 오른쪽에 배지를 표시한다.

잘못된 데이터는 빈 배열로 정규화한다. 사용량 오류 때문에 활동 말풍선 자체가
실패하거나 사라지지 않는다.

## 테스트

- 300분·10080분 창을 순서와 무관하게 5h·7d로 변환한다.
- 사용률 반올림, 0~100 보정, 초기화 완료, 누락·잘못된 창을 검증한다.
- 다중 활동과 Codex 작업 중 조건에서만 `usageBadges`가 붙는지 검증한다.
- DOM renderer가 오른쪽 배지 텍스트와 접근성 이름을 만들고 잘못된 값은 숨기는지
  검증한다.
- 기존 활동 상태, 서브에이전트 배지, 사용량 카드 테스트를 포함한 전체 테스트를
  실행한다.

## 제외 사항

- 여러 Codex 계정의 한도를 한 헤더에서 합산하지 않는다.
- 남은 토큰 수나 요청 수를 추정하지 않는다.
- AGY·Claude 한도를 같은 헤더에 추가하지 않는다.
- 사용량 조회를 위한 주기적 네트워크 요청을 추가하지 않는다.
