# 활동 상태 아이콘 개선 설계

## 목표

현재 유니코드 기호 기반 활동 상태를 CodePet 전용의 직관적이고 일관된 아이콘으로 교체한다. 아이콘은 작은 말풍선에서도 선명해야 하며 모델, 추론 강도, provider 이름과 접근성 정보는 그대로 유지한다.

## 시각 방향

- 이미지 생성으로 전체 아이콘 세트의 형태, 분위기, 색상 관계를 먼저 탐색한다.
- 생성 결과는 스타일 참고 자료로만 사용하고 앱에는 직접 포함하지 않는다.
- 실제 아이콘은 동일한 16x16 좌표계와 1.75px 선 굵기를 사용하는 인라인 SVG로 재구성한다.
- 둥근 선 끝과 모서리를 사용해 펫 UI의 부드러운 인상과 맞춘다.
- 장식보다 상태 인지 속도를 우선하며, 아이콘 하나에 의미 하나만 담는다.

| --- | --- | --- |
| 작업 중 | 회전하는 진행 링 | accent |
| 요청 확인 중 | 눈 | info |
| 응답 작성 중 | 반짝이는 펜촉 | accent |

| 자료·파일 확인 중 | 문서와 돋보기 | info |
| 이미지 생성 중 | 이미지와 반짝임 | violet |

## 구현 구조

`activity-title.js`는 유니코드 문자가 아니라 안정적인 아이콘 ID를 반환한다. `bubble.js`는 허용 목록에 있는 ID만 SVG 노드로 렌더링한다. 아이콘 경로 정의는 별도 모듈에 두어 상태 판정과 시각 표현을 분리한다.

SVG는 `currentColor`를 사용한다. CSS가 상태별 의미 색상을 제공하되 사용자 지정 말풍선 글자색과의 대비가 부족하면 기본 의미 색상을 유지한다. 진행 상태에만 짧고 절제된 회전 또는 펄스 애니메이션을 적용하며 `prefers-reduced-motion`에서는 애니메이션을 끈다.

## 접근성

- SVG는 장식 요소로 `aria-hidden="true"`를 유지한다.
- heading의 `aria-label`에는 기존 한국어 상태, provider, 모델, 추론 강도를 모두 보존한다.
- 색상만으로 상태를 구분하지 않고 각 상태의 실루엣을 서로 다르게 만든다.
- 완료와 실패처럼 중요한 결과는 움직임 없이 형태와 색상으로 표현한다.

## 검증

- 모든 상태가 예상 아이콘 ID로 매핑되는 단위 테스트를 먼저 작성한다.
- 허용되지 않은 아이콘 ID가 DOM에 임의 SVG를 주입할 수 없는지 확인한다.
- SVG 렌더링, 접근성 이름, busy dot 제거, reduced-motion CSS를 검증한다.
- 전체 테스트와 패키지 빌드를 실행한다.
- 일반 패키지 앱에서 1x/2x 화면의 단일·다중 활동 제목을 확인한다.

## 범위 제외

- 설정 화면과 트레이 메뉴 아이콘 변경
- 외부 아이콘 라이브러리 의존성 추가
- 생성된 래스터 이미지를 런타임 자산으로 포함
