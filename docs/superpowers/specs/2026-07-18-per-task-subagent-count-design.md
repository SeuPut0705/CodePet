# 작업별 서브에이전트 수 표시 설계

## 목표

CodePet 활동 말풍선에서 각 Codex 작업이 현재 사용 중인 서브에이전트 수를 보여준다. 서브에이전트의 내부 작업 제목과 메시지는 계속 숨기고, 최상위 사용자 작업 제목 옆에 활성 하위 에이전트 총수만 표시한다.

표시 예시는 다음과 같다.

`[상태 아이콘] CodePet · Sol · Medium  [에이전트 아이콘 ×3]`

활성 서브에이전트가 없으면 배지를 렌더링하지 않는다.

## 집계 기준

- `session_meta.payload.thread_source === "subagent"`인 rollout만 서브에이전트로 분류한다.
- `session_meta.payload.parent_thread_id`로 부모 관계를 구성한다.
- 직속 자식뿐 아니라 중첩된 모든 활성 자손을 최상위 사용자 작업에 합산한다.
- `task_started`부터 활성으로 계산한다.
- `task_complete`, `turn_aborted`, stale 정리에서 비활성으로 계산한다.
- 부모 관계가 순환하거나 최상위 사용자 작업을 찾을 수 없으면 해당 항목은 표시 집계에서 제외한다.
- AGY와 Claude 활동에는 서브에이전트 배지를 표시하지 않는다.

## watcher 구조

`CodexWatcher`는 사용자 rollout과 서브에이전트 rollout을 서로 다른 경로로 처리한다.

1. 완성된 첫 `session_meta` JSON을 파싱해 thread 종류와 부모 thread ID를 캐시한다.
2. 사용자 rollout은 기존처럼 메시지, 도구 상태, 완료 상태를 발행한다.
3. 서브에이전트 rollout은 수명 주기 이벤트만 읽고 메시지와 도구 활동은 발행하지 않는다.
4. 서브에이전트 활성 집합이나 부모 관계가 바뀌면 각 최상위 사용자 thread의 재귀 합계를 계산한다.
5. 합계가 달라진 사용자 thread에 `subagent-count-changed` 이벤트를 발행한다.

사용자 rollout 제한과 서브에이전트 감시 제한은 분리한다. 서브에이전트가 많아도 최근 사용자 작업이 목록에서 밀리지 않아야 한다. 첫 메타데이터가 부분 기록된 파일은 다음 poll까지 보류하며 사용자 rollout으로 추측하지 않는다.

## 상태와 렌더링

main process는 `subagent-count-changed`를 받으면 해당 thread의 `ActivityBubbleState`를 갱신한다. 상태에는 검증된 0 이상의 정수 `subagentCount`를 저장한다.

배지는 제목 문자열에 합치지 않고 별도 구조화 필드로 renderer에 전달한다. `bubble.js`는 기존 상태 아이콘과 제목 뒤에 작은 에이전트 아이콘, 곱하기 기호, 숫자를 묶어 렌더링한다. 배지는 제목보다 약한 대비를 사용하지만 숫자는 작은 크기에서도 읽을 수 있어야 한다.

접근성 이름에는 `활성 서브에이전트 3개`처럼 실제 개수를 추가한다. 장식용 에이전트 SVG 자체는 `aria-hidden="true"`로 유지한다.

## 복원과 오류 처리

- 앱 시작 시 최근 subagent rollout의 마지막 수명 주기 이벤트를 확인해 진행 중인 수를 복원한다.
- 완료 이벤트가 누락된 rollout은 기존 stale 기준에 따라 집계에서 제거한다.
- 부모 작업이 화면에서 제거되면 배지를 렌더링하지 않지만 내부 집계는 남은 수명 주기 동안 안전하게 정리한다.
- 잘못된 parent ID, 손상된 JSON, 알 수 없는 thread source는 화면 오류를 만들지 않고 집계에서 제외한다.
- 메타데이터 분류 캐시는 상한을 두어 장시간 실행 시 무한히 커지지 않게 한다.

## 검증

- 직속 서브에이전트 시작·완료에 따라 `0 → 1 → 0`으로 변하는 테스트
- 중첩된 서브에이전트가 최상위 작업에 재귀 합산되는 테스트
- 여러 사용자 작업의 개수가 섞이지 않는 테스트
- 서브에이전트 메시지와 도구 활동이 계속 숨겨지는 테스트
- 부분 `session_meta`, 순환 부모 관계, stale 종료 테스트
- 앱 시작 시 활성 서브에이전트 수 복원 테스트
- 배지 0 숨김, 양수 표시, 접근성 이름 DOM 테스트
- 전체 테스트와 macOS 패키지 빌드
- 일반 패키지 앱에서 실제 서브에이전트를 실행해 작업별 배지 증가·감소 확인

## 범위 제외

- 서브에이전트별 이름, 모델, 메시지, 진행 내용 표시
- 배지를 눌러 내부 작업 목록을 여는 기능
- 과거 최대 동시 수나 누적 실행 수 통계
- AGY·Claude의 하위 작업 집계
